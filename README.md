# Editor de Texto Simples

Um editor de texto desenvolvido em Pascal, executado diretamente pelo terminal.

## Funcionalidades

- Criar novos textos
- Digitar textos com múltiplas linhas
- Exibir o conteúdo escrito
- Salvar textos em arquivos
- Abrir arquivos existentes
- Menu interativo pelo terminal

## Tecnologias

- Pascal
- Free Pascal Compiler (FPC)

## Como executar

Compile o programa:

```bash
fpc EditorTextoSimples.pas
```

Execute:

```bash
./EditorTextoSimples
```
